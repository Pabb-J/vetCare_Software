### Objetivo del proyecto
VetCare_Software es una aplicación web desarrollada en **Flask** para la gestión de turnos y registros de mascotas en clínicas veterinarias.

### Tecnologías utilizadas
- Python 3.x
- Flask
- HTML, CSS, Bootstrap
- SQLite (base de datos)
- Git/GitHub (control de versiones)

### Cómo usar esta documentación
Cada archivo dentro de `docs/` está orientado a un público distinto:
- **INSTALLATION.md** → guía técnica para instalar y ejecutar el sistema.
- **ARCHITECTURE.md** → explicación de la estructura interna del código.
- **USER_MANUAL.md** → guía práctica para usuarios finales (veterinarios y clientes).
