# Manual de Usuario - VetCare_Software

Este manual está dirigido a veterinarios y clientes que utilizan la aplicación **VetCare_Software** para gestionar turnos y registros de mascotas.

---

## 1. Introducción
VetCare_Software es una aplicación web que permite:
- Registrar mascotas y sus datos básicos.
- Agendar turnos en la clínica veterinaria.
- Consultar historial de turnos y datos de atención.

---

## 2. Requisitos previos
- Navegador web actualizado (Chrome, Firefox, Edge).
- Conexión a internet.
- Usuario y contraseña proporcionados por la clínica.

---

## 3. Primeros pasos
1. Abrir la aplicación en el navegador.  
2. Iniciar sesión con usuario y contraseña.  
3. Acceder al menú principal para ver las opciones disponibles.

---

## 4. Funciones principales

### Registrar mascota
- Ingresar nombre, especie, raza y edad.
- Guardar los datos para futuras consultas.

### Agendar turno
- Seleccionar mascota registrada.
- Elegir fecha y hora disponibles.
- Confirmar el turno.

### Consultar historial
- Ver turnos pasados y próximos.
- Revisar datos de atención y observaciones.

## 6. Resolución de problemas comunes
- **No puedo iniciar sesión**: verificar usuario y contraseña.  
- **No aparece mi mascota**: asegurarse de haberla registrado correctamente.  
- **No se guarda el turno**: revisar conexión a internet y volver a intentar.

Para soporte técnico, comunicarse con el administrador de la clínica.
